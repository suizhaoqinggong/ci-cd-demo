# CI/CD Demo Project

React + Vite + TypeScript frontend & Node.js + Express + TypeScript backend.

- `apps/frontend`: React + Vite + Vitest
- `apps/backend`: Express + TypeScript + `node:test`
- `.github/workflows/hello-world.yml`: Hello World CI
- `.github/workflows/ci.yml`: Frontend & Backend Lint / Test / Build CI
- `.github/workflows/static.yml`: Frontend GitHub Pages CD
- `.github/workflows/deploy-ecs.yml`: Full-stack build & deploy to ECS
